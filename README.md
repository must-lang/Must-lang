Must - это компилируемый язык програмирования обшего назначения , его синтаксис полностью индитичен C но с 3  главными отличеями:
1. Все стандартные библиотеки C полключяються автоматически.


2. Типы данные выберяються и подставляються автоматически максимально оптимизированно.

 
3. Оператор « ; » раставляеться везде автоматически но не убран полностью.


Компилятор Must это Masika в ней прописан флаг максимальной оптимизации.


Проект Must создан для того что быстро разработать иструмент с помошью которого можно быстро на писать C , что бы он работал быстрее C , и сам компилятор был быстро разработан.


Must - это быстрота во всём так и в разработке так и в работе программ написаных на Must.


По суте Must это C с добалеными удобными вешями из Rust и Go.
